# Typing Speed Test – Ten Finger Typing

## About the Project
This project is a typing speed test application developed using Python and Pygame.

It helps users improve their typing speed and accuracy through typing exercises.

## Features
- Typing speed measurement (WPM)
- Typing accuracy calculation
- Different difficulty levels
- Typing timer
- User performance records
- Simple graphical interface

## Technologies Used
- Python
- Pygame

## Installation

First, install Python on your computer.

Then install Pygame:

```bash
pip install pygame
```

## How to Run

1. Download or clone this repository.
2. Open the project folder.
3. Run the following command:

```bash
python main.py
```
